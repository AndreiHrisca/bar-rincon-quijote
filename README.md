# El Rincón del Quijote

Carta digital, reservas, personal y almacén para el bar El Rincón del Quijote
(Ciudad de los Ángeles, Madrid).

```bash
docker compose up -d
```

**La documentación está en [`docs/`](docs/):**

- [`docs/README.md`](docs/README.md) — cómo se levanta en local y cómo se despliega.
- [`docs/DECISIONES.md`](docs/DECISIONES.md) — cada decisión técnica y por qué.
- `docs/MANUAL-SANTI.md` — manual del día a día *(fase 11)*.
- `docs/MANUAL-COCINA.md` — una hoja para colgar en la cocina *(fase 11)*.
